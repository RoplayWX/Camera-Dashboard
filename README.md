# 📡 Camera Dashboard

**A personal weather monitoring dashboard for live camera feeds, radar imagery, and active weather warnings.**

🌐 **Live Website:** https://camera-dashboard-one.vercel.app  
💻 **GitHub Repository:** https://github.com/RoplayWX/Camera-Dashboard

---

## 🌦️ Overview

Camera Dashboard is a weather-monitoring web application designed to bring useful weather information and visual resources together in one convenient interface.

Whether you're monitoring developing storms, checking weather conditions, or viewing available camera feeds, the dashboard provides a centralized place to follow weather activity.

## ✨ Features

- 📹 **Live Camera Feeds** — Access available weather and traffic camera streams.
- 🌧️ **Weather Radar** — View radar imagery to monitor precipitation and developing storms.
- ⚠️ **Active Weather Warnings** — Keep track of weather alerts and warning areas.
- 🗺️ **Warning Polygons** — Visualize affected areas when supported by the displayed warning data.
- 🖥️ **Centralized Dashboard** — Access multiple weather-monitoring resources from one interface.
- 🌐 **Web-Based Access** — Open the dashboard through a supported web browser without installing a desktop application.

*Available features and data depend on the current implementation and the services providing the imagery or alerts.*

**Always rely on official National Weather Service alerts and local emergency management instructions for weather-related safety decisions.** Never use this dashboard as your sole source of emergency information.
